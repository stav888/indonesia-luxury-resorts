# 🏝️ NUSANTARA SANCTUARY — Ultra-Luxury Resorts Indonesia

A bespoke high-end luxury hospitality showcase engineered with **Next.js 15**, **React 19**, **Tailwind CSS**, and **GSAP** smooth animations.

Designed for high-net-worth travelers, private island buyouts, and transcendent nature experiences across Bali, Raja Ampat, Sumba, and Komodo.

---

## 💎 Features
- **Next.js 15 App Router** & **TypeScript**
- **GSAP Powered Animations** (Smooth entrance & timeline choreography)
- **Tailwind CSS Luxe Palette** (Deep emerald, imperial gold, raw sand)
- **Destinations Showcase** (Ubud, Uluwatu, Raja Ampat, Sumba, Komodo)
- **Signature Sanctuaries** (Amanjiwo, Nihi Sumba, Misool Eco Atoll)
- **Confidential Concierge Booking Engine**
- **Mobile First & Fully Responsive**
- **Zero-Config Vercel Deployment**

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/stav888/indonesia-luxury-resorts.git

# Enter project directory
cd indonesia-luxury-resorts

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the live experience.
